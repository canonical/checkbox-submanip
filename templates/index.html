Checkbox Submission Editor

This tool allows you to manually edit a Checkbox submission archive. To get started:

  1. Select the Checkbox submission (submission.tar.xz) you'd like to edit with the button below.
  2. Press the "Edit Submission" button.

Once you are satisifed, you can save your changes. A new Checkbox submission archive will be generated and you will be able to download it.

Please note: Submissions generated with this tool should not be uploaded to C3.
